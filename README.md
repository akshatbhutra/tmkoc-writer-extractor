Stack: Python with yt-dlp and ffmpeg (clip download), OpenCV and NumPy (frame sampling and preprocessing: upscaling, CLAHE, green-channel Otsu thresholding), and EasyOCR on PyTorch (Hindi + English OCR).
Logic: Regex fuzzy keyword matching plus difflib similarity for consensus voting and known-name snapping, with CSV output (UTF-8 BOM) via the standard library.
